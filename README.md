# Analisis-Cluster-Jaringan-Internet-Gratis
Projek ini bertujuan untuk mengelompokkan (clustering) tingkat wilayah kecamatan berdasarkan sebaran dan ketersediaan titik jaringan internet gratis. Menggunakan algoritma K-Means dan Fuzzy C Means Clustering, analisis ini memetakan wilayah ke dalam beberapa kelompok untuk melihat ketimpangan maupun pemerataan akses fasilitas internet publik.

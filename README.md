# Analisis-Cluster-Jaringan-Internet-Gratis

Deskripsi Proyek: Proyek ini membahas pengelompokan wilayah berdasarkan karakteristik persebaran jaringan internet gratis di Kota Gorontalo. Analisis dilakukan menggunakan metode K-Means dan Fuzzy C-Means untuk mengidentifikasi pola pengelompokan wilayah berdasarkan variabel yang digunakan.

Metode: K-Means Clustering dan Fuzzy C-Means Clustering.

Tools: Python, Google Colab.

Konteks Proyek: Proyek akademik – Mata Kuliah Topik Statistika
